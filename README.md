# SecureProductApi 🔐

A Secure REST API built with **Spring Boot + Spring Security + JWT** for managing products with user authentication.

## 🚀 Features
- User Registration & Login with JWT Authentication
- Secure Product CRUD APIs
- Spring Security + JWT Token Validation
- BCrypt Password Encryption

## 🛠️ Tech Stack
- Java 17
- Spring Boot 3.x
- Spring Security
- JWT (JSON Web Token)
- Maven
- H2 Database
